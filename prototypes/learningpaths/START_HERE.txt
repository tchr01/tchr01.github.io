❓ COMMON QUESTIONS
Q: Does this need internet?
A: Only for first load (CDN libraries). After that, works offline.

Q: Can I edit the demo data?
A: Yes! Edit app.js arrays (demoPersonas, demoTopics)

Q: Will my changes be saved?
A: Yes, in browser localStorage. Clear browser data to reset.

Q: What browsers work?
A: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+

🔧 TROUBLESHOOTING
Problem: Blank page
→ Check JavaScript console for errors
→ Try hard refresh (Cmd+Shift+R)

Problem: Styles broken
→ Check network tab for failed CDN requests
→ Try incognito mode

Problem: Changes not saving
→ Check if localStorage is enabled
→ Try different browser
