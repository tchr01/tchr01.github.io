Help & Instructions

How to Use Package Validator:

  1. Click "Choose File" and select a SCORM 1.2 package (.zip file)
  2. Click the "Validate" button to analyze the package
  3. Review the validation results:
    • Errors - Critical issues that must be fixed
    • Warnings - Best practices and recommendations
    • Info - Package details and structure
  4. Fix any errors in your package and re-validate

What Gets Validated:

  • Presence and validity of imsmanifest.xml
  • Required SCORM 1.2 structure (manifest, organizations, resources)
  • All referenced files exist in the package
  • Launch files are accessible
  • Metadata and schema version
  • Resource types and organization structure

Help & Instructions

How to Use API Tester:

  1. This tool simulates an LMS SCORM API for testing
  2. Click "Initialize" to start a SCORM session
  3. Use quick tests or custom calls to test your SCORM wrapper
  4. Check the log to see all API calls and responses
  5. Click "Finish" to end the session

Common SCORM 1.2 Data Elements:

  • cmi.core.lesson_status - completed, incomplete, passed, failed, not attempted
  • cmi.core.score.raw - Score value (0-100)
  • cmi.core.score.min - Minimum score
  • cmi.core.score.max - Maximum score
  • cmi.core.session_time - Time in HH:MM:SS format
  • cmi.suspend_data - Custom data (max 4096 chars)
  • cmi.core.student_id - Student identifier (read-only)
  • cmi.core.student_name - Student name (read-only)
