Why This Project Exists

Higher education needs a better way to create engaging, interactive online learning experiences that stand out from competitors and can be deployed at scale.

The Problem

  • ✗ Video fatigue: Students are overwhelmed with passive content that doesn't engage
  • ✗ Slow development cycles: Faculty want to see prototypes but LXDs can't demo until weeks later - ideas go stale
  • ✗ Expensive authoring tools: $1,000-$3,000/year per designer, steep learning curves
  • ✗ Generic templates: Cookie-cutter content that doesn't differentiate your institution
  • ✗ Scale vs. quality trade-off: Fast development sacrifices uniqueness and engagement
  • ✗ Competitive pressure: OPMs and other institutions investing heavily in learning tech

Our Solution

  • ✓ Interactive > Passive: Build engaging hands-on activities that students actually complete
  • ✓ Rapid prototyping: LXDs go from idea to working demo in the LMS in minutes - show faculty real prototypes, iterate on the fly
  • ✓ AI-powered development: Use Claude Code to build and customize - zero licensing costs, no coding required
  • ✓ Full creative control: Unique, branded experiences that differentiate your institution
  • ✓ Build once, customize rapidly: 2-3 hours first build, then 30 min per customization
  • ✓ Scalable across institution: Deploy to unlimited courses, campuses, and programs

Technical Overview

Technology Stack

  • • SCORM: 1.2 standard (universal compatibility)
  • • Frontend: HTML5, CSS3, JavaScript (ES6+)
  • • Styling: Tailwind CSS (customizable)
  • • Build: Node.js, npm scripts
  • • Development: Claude Code for customization
  • • Version Control: Git-ready

Compatibility & Standards

  • ✓ LMS: Any SCORM 1.2 compliant system
  • ✓ Browsers: Chrome, Firefox, Safari, Edge
  • ✓ Mobile: iOS, Android (responsive design)
  • ✓ Accessibility: WCAG 2.1 AA compliant
  • ✓ Standards: Section 508, ADA compliant
  • ✓ Security: No server-side code, HTTPS ready
